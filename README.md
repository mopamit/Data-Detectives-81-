# בלשי הנתונים: מי מטעה עם הנתונים? – Prismind

משחק לכיתה ז׳ (שער עצמאות). בכל תיק שלוש דמויות טוענות טענות ומביאות טבלה או דיאגרמה. התלמיד מחליט מי צודק ומי מטעה, מזהה את הטעות, ומכריע מה באמת נכון.

הטעויות שהמשחק מלמד לזהות: השוואת שכיחות במקום שכיחות יחסית, ציר שלא מתחיל ב־0, התעלמות מהמקרא בפיקטוגרמה, דיאגרמה שלא מתאימה לטבלה, "רוב" כשהחלק קטן מחצי, טבלה שלא כוללת את כל הנתונים, וחישוב שגוי של שכיחות יחסית.

4 תיקים: הכיתה הספורטיבית, בחירות לנציג השכבה, סקר המזנון, הספרייה. הנתונים, הדמויות ומי שמטעה מוגרלים בכל משחק.

`index.html` עצמאי לגמרי (פונט, לוגו, אייקונים וצלילים מוטמעים) ומתאים ל־GitHub Pages.
